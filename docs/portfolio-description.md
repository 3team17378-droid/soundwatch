# 포트폴리오 설명

도시 소음의 업로드부터 분류·검토·공간 통계까지 연결한 풀스택 환경 모니터링 프로젝트입니다. 단순 예측 UI를 넘어 접근 통제, 실패 복구, 모델 버전 추적, 개인정보 보존과 관리자 감사까지 구현했습니다.

설명 가능한 기술 선택: API 키 없는 재현 가능한 DEMO와 실제 ONNX 추론을 분리해 결과의 출처를 드러냅니다. 무보정 녹음을 절대 데시벨로 오인하지 않도록 dBFS만 표시합니다. 공개 지도는 사용자 동의·좌표 반올림·메타데이터 축소를 적용합니다.

확인된 성과는 테스트 보고서를 인용합니다. 분류 정확도·macro F1·실서비스 처리량은 측정 전이며 합성 샘플을 실환경 성능으로 주장하지 않습니다. 후속 과제는 실제 모델 평가, PostgreSQL·Docker E2E, 분산 작업 큐와 운영 모니터링입니다.
