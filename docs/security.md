# 보안과 보존

- Argon2 비밀번호 해시, 만료·issuer·audience 검증 JWT, DB 활성 상태 확인.
- 파일 UUID 저장, 사용자 경로 입력 차단, 인증 다운로드, 타인 ID에 404.
- MIME·확장자와 실제 FFmpeg 디코딩 검사, 크기·시간·큐 제한.
- 첫 WebSocket 프레임 인증과 origin 검사. 토큰 URL 기록 방지.
- React 문자열 이스케이프, 지도 popup textContent, Nginx CSP.
- 구조화 로그에 요청 ID·상태·처리 시간만 기록. 관리자 감사 로그는 권한 보호.
- 원본 기본 7일, 결과 90일. 시작 시·1시간 간격 정리, CLI cleanup 지원.
- 비동의 원본 삭제는 결과 특징·위치도 제거. 동의 시 파형·log-mel과 상세 텍스트 삭제, 위치 반올림·시간 일 단위 축소.

제한: JWT는 sessionStorage에 있어 XSS 방어가 중요합니다. 대규모 서비스에는 HttpOnly 세션 또는 별도 토큰 설계가 필요합니다. 로그인 throttling은 프로세스 메모리이며 재시작·다중 인스턴스에 공유되지 않습니다. 감사 로그의 사용자 관계·IP·사유는 운영상 개인정보이므로 별도 보존 정책이 필요합니다. 원본 소유자 연결을 포함한 내부 DB는 완전 익명 데이터가 아닙니다. 삭제는 파일·DB 간 분산 트랜잭션이 아니므로 운영 시 재시도·조정 작업을 강화해야 합니다.

공개 Git에서는 `.env`, 음성, 모델 가중치, DB, 작업·출력 폴더를 제외합니다.
