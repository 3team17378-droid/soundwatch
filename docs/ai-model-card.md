# 모델 카드

DEMO v1.0.0은 centroid·zero-crossing rate·RMS 변동·무음 비율과 수작업 prototype 거리로 결정론적 점수를 계산합니다. 학습·정확도 검증·확률 보정이 수행되지 않았습니다. 실제 분류기로 사용하지 않습니다.

MODEL은 ONNX Runtime CPU를 사용합니다. float32 `[1,160000]` mono 16kHz 입력, `[1,10]` 유한 logits 출력 계약입니다. 10초 구간으로 나누어 마지막 구간을 0 padding하고 softmax 점수를 평균합니다. 클래스 순서는 `app/ml.py`의 CLASSES와 같습니다. YAMNet·PANNs는 별도 변환·클래스 매핑이 필요합니다.

모델 이름·버전·파일 SHA256, 정규화 파형 SHA256, 전처리 버전·샘플레이트·구간 길이·임계값을 저장합니다. 추론 시간에는 모델 생성/로드가 포함됩니다. MODEL 실패를 DEMO로 몰래 대체하지 않습니다.

한계: 복합 소음·녹음기 차이·배경 잡음·도메인 이동·짧은 이벤트·오탐. 절대 dB SPL을 산출하지 않습니다. 무음은 -120 dBFS 바닥값이며 silence_ratio는 프레임 RMS<0.001 비율입니다. 정확도·macro F1은 라벨링한 독립 검증셋을 확보한 뒤 평가해야 합니다.
